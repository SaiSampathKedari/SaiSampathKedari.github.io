# saisampathkedari.github.io

Personal academic website of Sai Sampath Kedari, served by GitHub Pages as a plain static site (no build step).

- `index.html`: homepage
- `writing/`: notes and write-ups
- `static/`: images, logos, and videos used by the pages
- `files/`: CV

The previous site (Jekyll, academicpages theme) is preserved at the git tag `old-site-2026`.
